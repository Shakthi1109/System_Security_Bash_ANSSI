STEPS TO RUN THE SCRIPTS:

1. Unzip the folder JIANG_MURUGAVEL_TP2.zip

2. Move into the directory using cd ./JIANG_MURUGAVEL_TP2

3. Use command chmod +x runall.sh if needed

4. You will find all the rules and their supporting files in this folder.
   Namely rule10.sh, rule11.sh, rule12.sh, ... and so on.

5. Run the command ./runall.sh in the current directory to run the
   scripts.

6. The scripts check the respective ANSSI rules and displays OK or KO as
   output.

For the rules 12, 22, 23 and 38, files content1_R12, content2_R12, r22reco, r23reco, r38reco (rules recomendations) need to be in the same directory as ruleX.sh.
