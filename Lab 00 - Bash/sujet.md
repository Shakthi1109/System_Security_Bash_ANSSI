Introduction to bash
=======

1- Main script
---------------

Hello everyone, today you will create a little script to manage the student notes of the class. Unfortunately, your only tool to do so is bash.

Create a file with the shebang bash. make it executable and run a Hello world.

Now the purpose of this script is to take 2 arguments: the name of the student and the note.
Don't forget to have an help ! (myscripy -h)
Then, in a file, it write : student name (the note) : the appreciation.
the appreciation is:
“very good” if the score is between 16 and 20;
“good” when it is between 14 and 16;
“fairly well” if the mark is between 12 and 14;
“medium” if the score is between 10 and 12;
“insufficient” if the score is less than 10.
