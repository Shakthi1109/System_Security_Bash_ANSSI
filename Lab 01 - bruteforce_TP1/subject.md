SUBJECT 00
=======

1- A little bit of c language
-----------

In the session you will create a c binary. This binary have to check that the first parameter is the good password. To do so a string comparison must be done between the parameter given in command line and the password in the binary: i.e ./test password

In case of a good password, the binary will only print Access granted.  In case of a bad password the binary will print "Bad password".

2- Time to crack
-----------
In this phase you will choose a password with a maximum length of 5 characters (without special ones) and give the binary to your neighbor.

You will have to brute force that password. Good luck

Maybe python can help you do so.
